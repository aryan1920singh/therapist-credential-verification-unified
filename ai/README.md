# AI - Therapist Credential Verification System

This directory is reserved for AI development and experimentation.

## Planned Components

1. Credential document classification.
2. PDF text extraction and OCR experiments.
3. Text embeddings.
4. Vector similarity search using PostgreSQL pgvector.
5. Retrieval-Augmented Generation (RAG).
6. AI evaluation and performance analysis.

## Development Workflow

AI models and RAG pipelines will initially be developed and evaluated in Kaggle notebooks.

After evaluation, suitable components will be packaged for backend integration.

## Important

- Do not upload private documents or sensitive datasets.
- Do not commit API keys, passwords or environment secrets.
- Do not commit large trained model files without agreeing on a storage strategy.
- Keep experiments, datasets and production integration clearly separated.
