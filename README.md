# Therapist Credential Verification System

A unified repository for the Therapist Credential Verification System.

## Project Structure

- backend/ - FastAPI backend, PostgreSQL database integration, document processing and APIs.
- frontend/ - Frontend application developed separately by the frontend team.
- ai/ - AI classifier, document extraction experiments, embeddings and RAG development.
- docs/ - Project documentation, architecture and integration guides.

## Development Status

Backend foundation and document processing modules are under development.
AI/RAG development and frontend integration are planned.

## Important

Do not commit environment files, passwords, private documents, datasets containing sensitive information, or local virtual environments.
