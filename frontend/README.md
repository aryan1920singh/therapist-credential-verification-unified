# Frontend - Therapist Credential Verification System

This directory is reserved for the frontend application.

## Purpose

The frontend will provide the user interface for:
- Therapist registration and login.
- Therapist profile management.
- Credential document uploads.
- Credential verification status tracking.
- Reviewer dashboard and verification decisions.
- Communication with the FastAPI backend.

## Development

The frontend will be developed independently by the frontend team.

## Integration

The frontend will communicate with the backend through REST API endpoints.

Backend API documentation during development:
http://localhost:8000/docs

## Important

- Do not modify backend files without coordinating with the backend developer.
- Do not commit node_modules, build folders, environment secrets or API keys.
- Document required environment variables in a .env.example file.
